# Учебный портал

Три вкладки: Институт управления, Институт дипломатии, Национальная школа
госполитики. По два курса в каждом институте, по три темы в курсе и три страницы
в каждой теме. Список тем расположен слева, материал справа. Есть изменяемые
отметки «Пройдено / Не пройдено», короткие тесты к темам и итоговые тесты с
объяснением ответов.

Добавлены регистрация и вход по email, выход, подтверждение email и восстановление
пароля через Supabase. Каждый аккаунт имеет собственный прогресс, который
сохраняется в Supabase и может загружаться на другом устройстве.

Сайт собирается Vite и подготовлен для GitHub → Vercel. Инструкция подключения
и запуска: DEPLOY.md. Для локальной разработки нужны `npm ci` и `npm run dev`,
а также реальные публичные настройки проекта Supabase.

Содержание: app.js (institutes, courses, topics, quiz). Авторизация: auth.js.
Оформление: styles.css. Структура данных и правила доступа: supabase/schema.sql.
Материалы демонстрационные и требуют адаптации под вашу учебную программу.
Учебные документы не загружаются и не передаются сторонним сервисам.
